# Site liaa-erik.github.io (LIAA 2026.2, RubricPro)

Página única, sem build. Para publicar no GitHub Pages:

1. Crie uma conta ou organização no GitHub chamada `liaa-erik` (formato pedido na Atividade 13: `<disciplina>-<nome>.github.io`).
2. Crie nela o repositório público `liaa-erik.github.io`.
3. Envie `index.html` e a pasta `assets/` para a branch `main`.
4. Em Settings → Pages, deixe "Deploy from a branch" → `main` / `(root)`.
5. Em 1–2 minutos o site abre em https://liaa-erik.github.io

Vídeo: `assets/liaa.mp4` (2:43), com capa `assets/liaa-poster.jpg` e legenda `assets/liaa.pt-BR.vtt`, embutido no bloco `<div class="video">` do topo.

Seção "Lado a lado": gráficos gerados no próprio HTML a partir do summary.json da rodada 2026-11-23T16-25-56 (constante `R` no script). Para outra rodada, troque os números em `R` e os textos da seção.
